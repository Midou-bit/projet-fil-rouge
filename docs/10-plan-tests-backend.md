# Plan de tests backend

## Périmètre et lecture

Ce plan relie les principales règles serveur et corrections du sprint aux tests xUnit réellement présents. Les tests unitaires ciblent les services purs ou contrôleurs isolés; les tests d'intégration démarrent l'API avec sa base SQLite de test et appellent ses routes HTTP.

Validation finale du 22 septembre 2026 :

```bash
dotnet test api.Tests/api.Tests.csproj -c Release --collect:"XPlat Code Coverage"
```

Résultat observé : **87 tests réussis, 0 échec, 0 ignoré**. Couverture Cobertura de l'API : **80,51 % lignes (4 522/5 616), 52,83 % branches (307/581) et 85,43 % méthodes (393/460)**. Dans le tableau, « Réussi » signifie que tous les cas et toutes les valeurs paramétrées cités ont réussi lors de cette exécution.

## Limites et compléments externes

La suite automatise les règles ci-dessus sans réaliser de transaction financière. Elle ne prouve pas à elle seule :

- un paiement Stripe test complet avec clés et compte Stripe externes ;
- la réception et la signature d'un webhook Stripe déployé ;
- le comportement sous charge distribuée ou derrière plusieurs instances ;
- la restauration opérationnelle d'une sauvegarde SQLite en production ;
- les contrôles d'infrastructure du fournisseur d'hébergement.
